# Global Venturers website

Single-page website for globalventurers.com.

- `index.html` – the whole site (all styles, scripts and images are built in).
- `CNAME` – tells GitHub Pages to serve the site on globalventurers.com.

## Publish with GitHub Pages
1. Repository → Settings → Pages.
2. Source: "Deploy from a branch", branch `main`, folder `/ (root)`. Save.
3. Under "Custom domain" enter `globalventurers.com` and tick "Enforce HTTPS" once it's available.
